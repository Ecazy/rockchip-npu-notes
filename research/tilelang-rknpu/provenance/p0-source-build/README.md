# P0 source-build replay

This directory is the compact, committed record of the 2026-10-23 source build.
The large source trees and native libraries stay untracked under `.src/`; their
archive/commit hashes, source-tree inventory, build configuration, compiler
commands, toolchain and library hashes are committed here and in
`../p0-source-build.json`.

## Inputs

All archives are exact GitHub archives at the locked commits and were fetched
through `https://gh-proxy.com/https://github.com/...` with resumable `curl`:

```text

tvm          4211874e9e4b8770fd20ad0d98ab80afd1df5028
```

Archive SHA-256 values are in `../p0-source-build.json` and the per-tree file
inventory is `source-tree-inventory.sha256`.  The source archives are unmodified;
no patches were applied to TileLang, TVM, tvm-ffi, dlpack or libbacktrace.

## Assembly and build

The checked-in logs were produced with:

- source trees: `.src/p0-build-src/tilelang` and `.src/p0-build-src/tvm`;
- TVM's `3rdparty/tvm-ffi`, `3rdparty/tvm-ffi/3rdparty/dlpack`,
  `3rdparty/tvm-ffi/3rdparty/libbacktrace`, and `3rdparty/dlpack` populated from
  the locked commits above;
- a symlink `tilelang/3rdparty/tvm -> ../../tvm` so TileLang's relative TVM
  include paths resolve;
- `TVM_ROOT` pointing at the locked TVM tree;
- `-DUSE_CUDA=OFF -DUSE_ROCM=OFF -DUSE_METAL=OFF -DUSE_LLVM=OFF
  -DUSE_ASCEND=OFF -DUSE_OPENCL=OFF -DUSE_GTEST=OFF -DHIDE_PRIVATE_SYMBOLS=OFF`;
- TVM FFI libbacktrace enabled from TVM's locked config, with the pinned
  libbacktrace source supplied;
- Cython 3.0.8 and Ubuntu 3.12.3 Python development headers as build-only
  dependencies.  Z3 and the Python `tvm_ffi` wrapper remain prebuilt and are
  explicitly listed in `../p0-source-build.json`.

The complete configure command, `CMakeCache.txt`, `TVMBuildOptions.txt`,
`compile_commands.json` and build logs are in this directory.  Build targets:

```text
tilelang
tilelang_cython_wrapper
```

Loaded native libraries are the source-built:

```text
libtilelang.so
libtvm_compiler.so
libtvm_runtime.so
libtvm_ffi.so
tilelang_cython_wrapper.cpython-312-x86_64-linux-gnu.so
```

The wheel's old native `.so` files are not first on `LD_LIBRARY_PATH` and were
not used for the source-build validation.
