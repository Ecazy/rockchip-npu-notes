# DPU 组置位窗口与驱动时间锚点（板端，单快照）

INTERRUPT_STATUS(0x0028) 与 RAW_STATUS(0x002c) 每个 run 各采一次，相位从提交入口起算；ioctl 返回与采样同一时钟（CLOCK_MONOTONIC_RAW）。

**读法（已修正）**：置位位 DPU_0/DPU_1 不是单次“块完成”脉冲，而是在作业大部分时间内置位、由 IRQ 路径清除的组级标记。下降沿与驱动的 `hw_elapse_time` 对齐；上升沿（约 11–18 µs）的机理尚未解释。

**限定**：每个 run 只有一个快照，p(置位 | φ) 是估计；只统计 workload 打印 BIT-EXACT 的 run；task_crossed 丢弃，task_ambiguous 保留。

## 本报告没有证明的

- 置位窗口不是单个块的完成时刻，也不给出任何 regcmd 位置或 task 内时刻；
- 上升沿的机理未知，不能当作“启动”或“完成”；
- 下降沿与 hw_elapse 对齐，是 IRQ 清除的间接证据；IRQ 时刻本身未直接观测；
- submit→kick 偏移未标定；由下降沿反推只能给出估计，且阈值是样本内拟合；
- 初版两两配对（未做奇偶平衡）的结果已撤回，不作为扰动估计；
- 数字仅适用于本板、本驱动版本与本负载。
